# 归档范围与可信度

简体中文 | [English](ARCHIVE.en.md)

本次归档日期：2026-10-17（Asia/Shanghai）。主线方案为原装遥控器 → ESP32-C3 → JBL 4305P，HA 经加密 ESPHome API 向同一 ESP32 发出按键。

## 包含什么

源码、版本固定的编译配置、上游组件许可证和 provenance、13 键协议、脱敏的验证摘要、HA 页面及连接图、人类部署说明、AI 操作约束、公开示例配置编译的 factory/OTA 产物、SHA-256 和构建清单。

Python 原型脚本用于复核研究方法，不是日常中转服务。`docs/archive/` 保存明确标为过时的方案比较。实际部署以 README 和 DEPLOYMENT 为准。

## 为什么不上传现网固件和原始抓包

现网固件会嵌入本机 Wi-Fi、API key 和 OTA 密码；整片 Flash/NVS 还可能包含 BLE 绑定密钥。蓝牙/HCI 抓包可能包含其他设备数据。它们保留在项目拥有者本地，不属于公开归档。

`jbl_protocol.json` 中的原始文件名和帧号是研究溯源，不代表这些原始文件在仓库内。公开提供 79 字节原始 HID 描述符及其哈希、完整按键字节、GATT 读取结果；静态检查可独立运行，原始抓包重放检查需要项目拥有者私下提供原始材料。

## 两类版本不可混淆

- **原设备实测版**：2026-10-17 19:52:45 +0800，针对原套设备固定身份。已验证项见 `evidence/validation-summary.json`。现网固件保留在本机，未作为公开产物上传。
- **归档可配置版**：把两端 MAC 改为部署参数，保留原有认证与订阅门禁。公开版本经过源码审查和编译检查；没有刷写本次正在使用的设备，也没有第二套同型号硬件实测。

公开示例 `.bin` 带假网络配置和公开演示密钥，仅用于核验构建及文件格式；推荐让 AI 从源码填写私有配置并编译部署。不要将示例密钥作为真实家居凭据。

## 复现与回退

使用固定版本构建。二进制包含时间等构建元数据，因此本仓库提供可复现构建流程和 SHA-256 核验，不声称跨机器逐字节相同。

OTA 失败时先保留旧设备状态并排查，不先清空 Flash。需要回退时使用本机保留的、与该设备匹配的上一个专用 OTA 镜像；新设备用对应源码重新生成专用镜像。公开 factory 镜像不能代替用户备份。

新版本归档应保存：源码 commit、编译器及框架版本、配置模板哈希、产物哈希、部署硬件、实际测试与未测试项。禁止将“蓝牙已连接”写成“音箱已执行”。
